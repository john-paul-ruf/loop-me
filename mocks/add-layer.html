Add a layer

You have 4 of 5 layers. A good composition usually mixes roles — structure, then texture, then mood on top.

Primary — centre-anchored structure
Secondary — full-frame texture
Overlay — final-pass mood
add-layer.html — FR-5, FR-6. Thirty-two types grouped by role, each with a static CSS impression so the names mean something before you've used them. Picking a type adds it on top with randomized in-bounds parameters — never a blank default that renders nothing. When the governor is warning, this dialog is unreachable and the Add layer button carries a visible reason (see states.html).
