⚠ Before you go in

What comes next flashes, strobes and moves quickly, with high-contrast colour. If you are sensitive to flashing lights, or you get migraines or seizures from moving images, please don't continue.

This setting is saved on this device only. Anyone you share a loop with still sees this warning first.

splash.html — FR-0 bare load. First paint on every load. No canvas frame renders and no timer runs behind this. Seed decode + offscreen pre-warm happen while this is up, so Enter → first frame is <200 ms. Focus is trapped in the dialog; on dismiss it moves to the main view. Never auto-dismisses, never counts down, never animates.
